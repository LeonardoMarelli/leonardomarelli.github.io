Welford's Recurrence and Sampling Moments

Online sampling mean and variance of penetration scores, one hacker at a time.

1. Welford's recurrence formulas

Mean (Knuth)

Mn = Mn−1 + (xn − Mn−1)/n

Sum of squares

We define the sum of squared deviations from the current mean as:

SSn = ∑i=1n(xi − Mn)²

Let δ = xn − Mn−1. From Knuth's recurrence formula for the mean:

Mn = Mn−1 + δ/n

For the previous n−1 observations, we can write:

xi − Mn = (xi − Mn−1) − δ/n

For the new observation:

xn − Mn = δ − δ/n = (n−1)δ/n

Substituting these expressions into the definition of SS:

SSn = ∑i=1n−1 [(xi − Mn−1) − δ/n]² + [(n−1)δ/n]²

Expanding the square:

SSn = SSn−1 − (2δ/n)∑i=1n−1 (xi − Mn−1) + (n−1)δ²/n² + (n−1)²δ²/n²

The cross term vanishes because the deviations from the previous mean sum to zero:

∑i=1n−1 (xi − Mn−1) = 0

Therefore, simplifying:

SSn = SSn−1 + (n−1)δ²/n

Since xn − Mn = (n−1)δ/n, we obtain the final recurrence formula:

SSn = SSn−1 + (xn − Mn−1) (xn − Mn)

Variance

sn² = SSn/(n−1) = ((n−2)/(n−1)) sn−1² + δ²/n, for n ≥ 3.

2. Code

export function welford(st, x) {
  st.n += 1;
  const d = x - st.mean;       // δ = x_n − M_{n−1}
  st.mean += d / st.n;         // M_n
  st.S += d * (x - st.mean);   // SS_n = SS_{n−1} + δ(x_n − M_n)
  return st;
}

The core logic is the three lines of the update. The counter and the return value are bookkeeping.

3. Experiment

Scores X ~ Binomial(10, 0.3), so μ = 3 and σ² = 2.1. Each of the m hackers attempts n systems, and Welford's formulas give that hacker's sampling mean x̄j and sampling variance sj². The table averages these across hackers and compares them with μ and σ².

4. What the numbers show

Comparison with μ and σ²

  • The average of the sample means matches μ = 3 at every n. The average of the sample variances matches σ² = 2.1 at every n.
  • Both estimators are unbiased: E[x̄] = μ, and E[s²] = σ² because of the 1/(n−1) divisor. Small gaps are simulation noise, of order sd/√m.

Effect of n on variability

  • Var(x̄) = σ²/n. The spread of sample means shrinks like 1/√n. Going from n = 5 to n = 1000 reduces it by a factor of about 14.
  • Var(s²) = (μ4 − σ⁴(n−3)/(n−1))/n also falls like 1/n, but with a larger constant. Here μ4 ≈ 12.68 and σ⁴ = 4.41, so Var(s²) ≈ 8.3/n, about four times Var(x̄) ≈ 2.1/n. Sample variances are therefore much noisier than sample means at the same n.

Relevance to inferential statistics

  • Unbiasedness: the sample statistics estimate μ and σ² with no systematic error, so a single hacker's values are meaningful estimates.
  • Precision: both variances tend to 0 as n grows, so the estimates concentrate around the true values (law of large numbers).
  • Standard error: sd(x̄) = σ/√n. Replacing σ with s gives s/√n, which is the basis for confidence intervals and t-tests. The CLT justifies the approximation for large n.
  • Welford's method: it processes the data in one pass with no stored trajectory, and it is numerically stable, which suits attempts that arrive one at a time.
