Riemann vs Lebesgue, and the Normal CDF

Numerical integration in two ways, and numerical evaluation of the standard normal CDF.

1. Riemann and Lebesgue integration

Problem

Approximate ∫f numerically in two ways: by partitioning the domain (Riemann) and by partitioning the range of values (Lebesgue). Compare accuracy, convergence and cost, and identify where the two approaches agree and where they do not.

Riemann (domain partition)

  • Split [a,b] into N subintervals Ii of length h = (b − a)/N.
  • Darboux sums: UN = Σ supIi f · h and LN = Σ infIi f · h. f is Riemann integrable iff UN − LN → 0, and the integral is the common limit.
  • For regular functions, sup and inf are estimated from M+1 equally spaced samples per subinterval (M even). The centre sample is reused for the midpoint sum Σ f(midi) · h, so the total cost is N(M+1) evaluations of f.
  • For 1/√x the sup and inf come from an exact oracle, because sampling cannot see the singularity. The sup on the first subinterval is +∞. On [i/N, (i+1)/N] the inf is f((i+1)/N), since f is decreasing. The midpoint sum is kept as the numerical approximation of the improper integral.

Lebesgue (range partition)

  • For f ≥ 0, ∫f dμ = ∫0∞ μ{f > t} dt (layer-cake formula). The t-integral is discretised with the midpoint rule and step δ.
  • When a level-set formula is known (1/√x, Dirichlet, Thomae), μ{f > t} is exact. Otherwise it is estimated on NL midpoints of the domain as μ ≈ (b − a) · #{f > t}/NL. Values are sorted once, and each level costs one binary search.
  • The step δ is chosen as δ = 1/K with K ≈ 10√N. With δ = 1/K, the jump levels t = 1 and t = 3 of the step functions lie on grid boundaries. The value of δ is shown in Table B.
  • For 1/√x the t-integral is truncated at T = 100. The exact level measure μ{f > t} = min(1, 1/t²) gives the tail ∫100∞ t−2 dt = 0.01, which is added analytically.

Functions

The seven functions of the homework, plus the Dirichlet function and Thomae's function. All test functions are non-negative on their domain, as the layer-cake formula requires.

Pathological functions

A floating-point number is a dyadic rational, so a computer cannot distinguish rational from irrational points. Sampling Dirichlet's function on a grid returns 1 everywhere, which is wrong. For Dirichlet and Thomae the code therefore uses exact oracles: the exact sup and inf on each interval, and the exact level measures. For Thomae, the sup on [i/N, (i+1)/N] is 1/q, where q is the smallest denominator of a fraction lying in that interval. The values for these two functions are theoretical, not sampled.

3. Ex.1 discussion

Same value when both apply

  • For the bounded regular functions (sin x, x², the two step functions, |x − ½|, sin x / x) both approaches converge to the same value. The differences in tables A and B are discretisation errors, not disagreement between the methods.
  • Lebesgue's criterion: a bounded f is Riemann integrable iff its set of discontinuities has measure zero. In that case the Riemann integral equals the Lebesgue integral.

Accuracy and convergence

  • Riemann, smooth f: the midpoint error is of order N−2, with constant proportional to f″.
  • Riemann, jump: if the jump does not lie on a grid boundary, the cell containing it is misclassified and the error is of order N−1. If the jump lies on a boundary, as for the step functions here (jump at ½, N even), the midpoint sum is exact and no N−1 error appears.
  • Riemann, 1/√x: the first cell contributes an error of about (2 − √2)√h, so the midpoint error is of order N−1/2.
  • Lebesgue, t-integral: the midpoint rule has error O(δ²) when μ{f > t} is C² in t, and error O(δ) in the presence of a jump in μ that is not aligned with the grid. For the step functions, the jump levels are aligned with δ = 1/K, so the O(δ²) behaviour holds on the smooth parts.
  • Lebesgue, sampled μ: for the functions of this experiment, each level has error O(1/NL) from the sampling of μ, which integrates to O(1/NL) over t.
  • Lebesgue, 1/√x: μ is exact, so the only errors are the midpoint error in t and the tail, which is added analytically. The result does not depend on N.

Efficiency

  • Riemann: N(M+1) evaluations of f, plus the sorting-free Darboux sums. For bounded one-dimensional f, this is usually the cheaper method.
  • Lebesgue: NL evaluations, O(NL log NL) sorting, and one binary search per level. Its advantage lies in what it can integrate, not in speed on these examples. Table A's timings let you check this.

Where the two approaches behave differently

  • Dirichlet: UN = 1 and LN = 0 for every N, so the gap never closes and f is not Riemann integrable. Lebesgue gives 0, because {f > t} = ℚ ∩ [0,1] has measure zero for t > 0.
  • Thomae: Riemann integrable, since its discontinuities lie on the rationals, a null set. The integral is 0. UN tends to 0 while LN = 0, so both approaches agree. Sampling would miss the structure of the function entirely.
  • 1/√x: the Riemann integral is improper, because f is unbounded near 0. The Darboux sums therefore show UN = +∞ for every N, and only the midpoint sums converge, slowly. Lebesgue handles the function directly, since μ{f > t} = min(1, 1/t²).

4. Ex.2 – Numerical computation of the normal CDF

Problem

Develop an efficient method for Φ(x) = ∫₋∞^x φ(t) dt, where φ(t) = e−t²/2/√(2π), implement it, and compare it with trusted reference values.

Why there is no elementary antiderivative

Liouville's theorem (1835) restricts the form an elementary antiderivative can take. Applied to f(x) = e−x²/2, it gives the following consequence: if ∫f were elementary, there would be a rational function R(x) with

∫ e−x²/2 dx = e−x²/2 R(x) + C.

Differentiating the right-hand side gives e−x²/2(R′(x) − xR(x)), so the condition becomes

R′(x) − xR(x) = 1. (∗)

No rational function R satisfies (∗):

  • R has no poles. Suppose R has a pole of order k ≥ 1 at a. Then R′ has a pole of order k+1 at a, while xR has a pole of order at most k there. The term R′ cannot be cancelled, so the left side of (∗) has a pole at a. The right side, 1, has none. Hence R has no poles, so R is a polynomial.
  • R is not a polynomial. Let R be a polynomial of degree n ≥ 0 with leading coefficient a ≠ 0. Then R′ has degree at most n−1, while xR has degree exactly n+1. So R′ − xR has degree n+1 ≥ 1 and cannot equal the constant 1. If R = 0, the left side is 0 ≠ 1.

The contradiction shows that ∫e−x²/2 dx has no elementary antiderivative, and so Φ is not elementary. The Risch algorithm (1968) makes this kind of test mechanical, but the argument above is enough here.

The role of erf

Φ(x) = ½(1 + erf(x/√2)), where erf(z) = (2/√π)∫₀^z e−t² dt. This is an exact analytical representation. But erf is itself non-elementary, so evaluating it at a point still requires numerics: truncated series with error control, continued fractions, or rational approximations.

Numerical approaches implemented

  1. Trapezoid rule on [0,|x|], N = 1000. Error O(N−2).
  2. Simpson's rule on [0,|x|], N = 200. Error O(N−4).
  3. Power series: Φ(x) = ½ + φ(x) Σn≥0 x2n+1/(1·3·…·(2n+1)). The series converges for every x in exact arithmetic, and its terms grow like x² before decaying. Stability: for moderate |x| (up to about 8) the implementation is accurate in absolute terms. For x negative and large in modulus, ½ + φ(x)S(x) subtracts two nearly equal quantities. The absolute error stays near machine precision, but the relative accuracy of the left tail is lost. For very large |x| the intermediate terms overflow, so the direct series is only suitable for moderate arguments and the hybrid method is preferred in the tails.
  4. erf hybrid: Kummer's series for erf when z = |x|/√2 < 2, and Laplace's continued fraction for erfc when z ≥ 2 (fixed depth 100). The survival function Q(x) = P(Z > x) = ½ erfc(x/√2) is computed directly, and Φ(x) = 1 − Q(x) for x ≥ 0, Φ(x) = Q(|x|) for x < 0. Limitation: for x ≥ 0, computing Φ(x) as 1 − Q(x) rounds to 1 once Q(x) is smaller than about 10−16, so the relative precision of the upper tail is lost. Using Q(x) directly avoids this loss, and Table D shows the difference.
  5. Polynomial approximation (Abramowitz–Stegun 26.2.17): O(1) cost, absolute error below 7.5·10−8. It is not reliable for tail probabilities of order 10−9, such as p-values.

Reference values

  • The values of Φ in the array REF are the standard tabulated values (Abramowitz & Stegun, Handbook of Mathematical Functions, Table 26.1). They follow from Φ(x) = ½ erfc(−x/√2), DLMF §7.2 (dlmf.nist.gov/7.2). Before final submission, compare them with R's pnorm (R stats documentation) or SciPy's norm.cdf (scipy.stats.norm).
  • The upper-tail reference values in Table D are Q(x) = P(Z > x), taken from the same DLMF relation.
  • General reference: DLMF chapter 7 on error functions, dlmf.nist.gov/7.

6. Ex.2 discussion

  • Quadrature: the trapezoid error falls as N−2 and Simpson's as N−4, so Table C should show Simpson's error dropping much faster per decade of N. Both are accurate but need many evaluations of φ.
  • Power series: accurate in absolute terms for moderate |x|. Its cost grows with |x|, and in the left tail it loses relative accuracy because of cancellation. It is a natural choice for moderate arguments only.
  • erf hybrid: it uses the series near the centre and the continued fraction in the tails. The survival function keeps relative accuracy in both tails at fixed cost, which matters for small tail probabilities.
  • Polynomial approximation: the fastest, but its error is bounded in absolute terms only.
  • Production libraries use minimax rational approximations, such as Cody's rational Chebyshev approximations, which are used in R's pnorm. These combine a low cost with near-machine accuracy.
